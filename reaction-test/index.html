Privacy

What is stored

  • Your profile name and colour, your runs, your goal, your mode and colour settings, and any friends' backup files you add.

Where it is stored

  • Only in this browser on this device (browser local storage). Nothing is sent to a server, because this site has no server.
  • There are no accounts, no ads, no analytics, and no third-party tracking scripts.

What is not protected

  • Anyone who uses this browser can see this data. It is not encrypted and is not behind a password.
  • GitHub Pages, which hosts the page, may keep standard visit logs (like IP address) as any web host does.
  • Clearing your browser data erases everything, so keep a JSON backup if you want to keep your history.

Your choices

  • Export a backup, delete your history, or delete everything at any time using the controls below.
Delete all my data

Removes your profile, runs, goal, colours, friends and settings from this browser. This cannot be undone.
